    Технологічний стек

    HTML5
    Розмітка сторінки: семантичні теги, форми з вбудованою перевіркою полів.
    CSS3
    Оформлення: змінні, flex і grid, адаптивність, світла й темна теми.
    JavaScript
    Поведінка в браузері: обробка форми, оновлення таблиці та сум без перезавантаження.
    Node.js
    Серверна частина SpendWise: обробка запитів, бізнес-логіка, робота з файлами чеків.
    Prisma ORM
    Опис моделей бази даних і запити до неї з коду.
    REST API
    Правила обміну між клієнтом і сервером: ресурси, методи GET, POST, PUT, DELETE, формат JSON.

    Як рухаються дані

    1. БраузерКористувач вводить витрату або завантажує фото чека.
    2. REST APIСервер перевіряє запит і дані.
    3. База данихТранзакції, рахунки й бюджети зберігаються через Prisma.
    4. OCR-сервісЗ фото чека виймається сума й повертається у форму.
